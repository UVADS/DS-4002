# Project 0: Is a hot dog a sandwich?

This project explores the popular question that has take over the internet: "Is a hot dog a sandwich?"

Initially, the following hypothesis was created: 1/4 of UVA undergraduate students believe a hot dog is a sandwich. This hypothesis was then explored via a google form sent out to a sample of UVA undergraduates. Data will be collected in a dataframe, where it will be cleaned and examined for trends and biases.
