# Project 0: Is a hot dog a sandwich?
This project surveys the UVA students to determine if they think a hot dog is a sandwich or not. The data dictionary is as follows:

Field Name | Description | Data Type | Possible Values
:--- | :--- | :--- | :---
`Timestamp` | Timestamp | DateTime | All hashtags (#) as it is redacted
`Year` | Year of UVA student | String | 5 possible values
`Gender` | The survey taker's gender | String | man/women/non-binary
`School` | The school that the survey taker is enrolled in | String | select all that apply
`is_sandwich` | The question of whether or not it is a sandwich | String | Yes/No
`statement_affinity` | How strongly survey taker feels about their answer | Integer | 1 to 10
`frequency` | The frequency of the survey taker's hot dog consumption | String | qualitative description
