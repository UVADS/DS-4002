# Hot Dog Survey Data

We collected data from students by having them filling out a survey. The raw data are uploaded in the file DS4002_HotDogSurvey_responses.xlsx, and the cleaned data is in the file HotDogSurvey_cleaned.xlsx. 

* Provenance: Surveyed the opinions of UVA undergraduate students on whether a hot dog is a sandwich or not.
